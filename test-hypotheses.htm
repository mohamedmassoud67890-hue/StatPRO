Les 5 Étapes d'un Test d'Hypothèses

  1. Formuler les hypothèses :
    • H₀ (Hypothèse nulle) : L'hypothèse de base, d'égalité (ex: μ = μ₀).
    • H₁ (Hypothèse alternative) : Ce qu'on cherche à prouver (ex: μ ≠ μ₀).
  2. Choisir le seuil de signification (α) : Généralement 5% (0.05). C'est le risque de rejeter H₀ alors qu'elle est vraie (Erreur de type I).
  3. Déterminer la statistique de test : Z si n ≥ 30 ou σ connu. T de Student si n < 30 et σ inconnu.
  4. Calculer la valeur observée : Utiliser les formules mathématiques avec les données de l'échantillon.
  5. Prendre une décision : Comparer la valeur calculée à la valeur critique lue dans la table.

Test Z vs Test T de Student

Le Test Z (Loi Normale)

Utilisé pour les grands échantillons (n ≥ 30) ou lorsque l'écart-type de la population (σ) est connu avec certitude.

Z = (x̄ - μ₀) / (σ / √n)

Le Test T de Student

Utilisé pour les petits échantillons (n < 30) et lorsque l'écart-type de la population est inconnu (on utilise 's' de l'échantillon).

T = (x̄ - μ₀) / (s / √n)
