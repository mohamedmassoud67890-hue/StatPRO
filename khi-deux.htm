Test d'Indépendance

Le test du Khi-Deux (χ²) permet de vérifier s'il existe une relation (dépendance) entre deux variables qualitatives (ex: Sexe et Préférence de couleur).

  • H₀ (Hypothèse Nulle) : Les deux variables sont indépendantes.
  • H₁ (Hypothèse Alternative) : Les deux variables sont liées (dépendantes).

Formule et Décision

On compare les effectifs observés ($O_{ij}$) avec les effectifs théoriques attendus ($E_{ij}$) si H₀ était vraie :

χ² = Σ [ (O - E)² / E ]
  • Effectif théorique (E) : (Total Ligne × Total Colonne) / Total Général.
  • Degré de liberté (df) : (Nombre de lignes - 1) × (Nombre de colonnes - 1).
  • Décision : Si le χ² calculé > χ² critique (table), on rejette l'indépendance (H₀).
