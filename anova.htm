À quoi sert l'ANOVA ?

L'Analyse de Variance (ANOVA) est utilisée pour tester si les moyennes de trois groupes ou plus sont égales. Elle remplace le test T de Student lorsqu'on a plus de deux groupes, pour éviter l'inflation du risque d'erreur alpha.

  • H₀ : μ₁ = μ₂ = μ₃ (Toutes les moyennes sont égales)
  • H₁ : Au moins une moyenne est différente des autres.

Les Composantes du Tableau

  • Inter-groupes (Between) : La variance causée par le traitement (la différence entre les groupes). Calculé via SSB et MSB.
  • Intra-groupes (Within) : La variance résiduelle ou l'erreur (la dispersion à l'intérieur de chaque groupe). Calculé via SSW et MSW.
  • Statistique F : C'est le ratio MSB / MSW. Si F est grand, la différence entre les groupes est significative par rapport au bruit interne.
